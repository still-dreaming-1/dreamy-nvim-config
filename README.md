# dreamy-nvim-config

My Neovim config.

The `main` branch is my new primary branch. It is my fresh attempt starting in August of 2026 to get a nice nvim configuration again. I have been primarilly programming in VSCode for quite some time now, so my nvim config has become very outdated. I switched to the built in plugin manager called vim.pack so that I don't have to keep changing plugin managers every time one becomes unmaintained or not modern enough. In the past there were certain features I could never get to work the way I wanted, which is largely why I switched to VSCode. Now that AI is very good for helping you get past sticking points and helping you figure things out when you are stuck, I might attempt to get a full featured nvim config again, or I might just get it to be a nice editor without all the IDE features. There is still some advantage to the latter even if I continue most of my development in VSCode because VSCode by default runs in an untrusted mode when you just use it as an editor with random files and directories, and this is probably a good thing.

The `master` branch is my historical branch from when I used to use nvim as my primary editor prior to creating the `main` branch. This used to be the main and only branch.
