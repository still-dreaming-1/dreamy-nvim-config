# dreamy-nvim-config

My Neovim config.

The `main` branch is my new primary branch. It will become more minimal until it is both usable and uses no plugins or a plugin manager. I now primarilly program in VSCode, and I no longer want to maintain a full featured nvim config that would utilize things like plugins. I don't want to deal with keeping the plugins up to date or keeping up with the latest recommendations for a plugin manager.

The master branch is my historical branch from when I used to use nvim as my primary editor.
